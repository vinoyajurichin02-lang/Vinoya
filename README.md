# Chizu Calculator

A responsive and aesthetic calculator website built for DCIT 26 Laboratory 1 using React, Vite, and Tailwind CSS.

## Requirements covered

- Calculator display
- Number buttons 0–9
- Addition, subtraction, multiplication, and division
- AC / clear
- Equals button
- React state
- React event handling
- Dynamic calculations
- Error handling for division by zero
- Keyboard support
- Responsive Tailwind CSS design
- User Guide and supported operations
- React components

## Run locally

Make sure Node.js is installed.

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite, usually:

```text
http://localhost:5173
```

## Production build

```bash
npm run build
```

## Deploy

This project can be deployed on Vercel or Netlify. For Vercel, import the GitHub repository and use the default Vite settings.
